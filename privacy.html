Privacy policy

Emmy is a private, non-commercial assistant for one household. It is not offered to the public.

Emmy accesses Google user data (Gmail, Google Calendar) only for the account that granted access and only to perform tasks its owner requests. Data is processed on the household's own server and is not sold, shared with third parties, used for advertising, or used to train AI models.

Emmy's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.
